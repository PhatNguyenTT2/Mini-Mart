# Source-bound reference configurations

These JSON files are strict, replayable examples from the frozen MP2 P2 grid.
They bind model identity, source commit/tree, relevant source-file hashes, and
the local adapter revision.

They are not selected configurations, checkpoints, benchmark results, or claims
of official-result reproduction. P4-G3 uses them only for source/import/config
and untrained fixture full-score qualification. Validation selection and any
training remain gated by later MP2 phases, and all metrics remain under the
independent shared evaluator.
