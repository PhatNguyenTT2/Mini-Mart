This matrix locks evidence and admissible routes; it does not authorize execution. A documented configuration means that a model author or framework maintainer names a dataset, command, or configuration. It does not mean the underlying data rights, bytes, transformation, split, or candidate policy are cleared. Raw metrics across rows are not directly comparable.

## Authority labels

| Label | Meaning |
|---|---|
| AUTHOR_OFFICIAL | Repository controlled by the paper/model authors and containing a named command or configuration. |
| FRAMEWORK_OFFICIAL | Maintainer-controlled framework configuration; useful, but not equivalent to the original model authors' reference pipeline. |
| PROVIDER_CANONICAL | Dataset provider release or institutional archival record. |
| PAPER_ONLY | Original paper documents the protocol but executable/data artifacts are not fully locked. |
| BLOCKED | A rights, access, provenance, version, or protocol gap prevents reference execution. |

## Locked conclusions

- The only provider-canonical datasets presently classified REFERENCE_REPRODUCTION_READY are MovieLens 1M and MovieLens 10M. “Ready” means the public evidence route is defensible; E4 still has to lock exact bytes and E5 still has to approve rights/privacy.
- Amazon-M2 is the only HARMONIZED_EXTERNAL_CANDIDATE in this lane. Its admissible claim is session-specific multilingual/cold-item external validation, not full basket/persistent-user validation.
- The Complete Journey and Instacart are the strongest later basket/history candidates, but neither may proceed on current evidence.
- Author-processed packs are never silently equated with canonical raw provider releases.
- No TEST asset was opened, no repository or dataset was downloaded, and no benchmark/result center was accepted.
