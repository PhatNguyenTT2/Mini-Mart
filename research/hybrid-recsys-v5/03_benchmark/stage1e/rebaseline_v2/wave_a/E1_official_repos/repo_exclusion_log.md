## Policy exclusions not counted as repository candidates

- Blogs, benchmark aggregators, Papers-with-Code-style indexes, package search results, arbitrary forks, mirrors, copied notebooks, and unlinked reimplementations were not admitted as evidence authorities. They therefore have no candidate record and contribute no technical claims.
- Repository stars, popularity, recent commit activity, badges, and search-result snippets were not used to infer correctness, license, compatibility, or author identity.
- A license badge was not accepted as a grant. A public repository without a license file remains `PENDING`, not implicitly open-source.
- Repo-bundled or linked datasets were not used to infer dataset ownership, license, redistribution rights, or benchmark admissibility.
- Pre-existing metrics, README leaderboards, and paper centers were not imported. All are `INVALID_FOR_PAPER` in this lane; raw numbers from different pipelines are never directly comparable.
